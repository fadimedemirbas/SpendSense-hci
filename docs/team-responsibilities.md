# SpendSense Team Responsibilities

## Team Structure

The project will be developed by three team members.

Each member has a primary responsibility area, but all members can contribute to shared components, testing, documentation, and integration.

---

## Member 1 — Onboarding & Spending Profile

### Main Responsibilities

- Welcome screen
- Basic Information onboarding
- Spending Habits questionnaire
- Spending Profile Result

### Main Tasks

- Create onboarding forms
- Manage onboarding state
- Create spending behavior questions
- Implement basic spending profile calculation
- Display spending profile percentages

### Example Output

45% Impulsive Decision Maker  
30% Bargain Hunter  
25% Planned Spender

---

## Member 2 — Goals, Dashboard & History

### Main Responsibilities

- Goal Creation
- Goals page
- Dashboard
- History & Insights

### Main Tasks

- Create goal form
- Create goal cards
- Display goal progress
- Create dashboard summary cards
- Create purchase history list
- Create simple insights section

---

## Member 3 — Purchase Decision & Backend

### Main Responsibilities

- Should I Buy It? screen
- Purchase Analysis screen
- Purchase Simulation
- Express backend

### Main Tasks

- Create purchase input form
- Send purchase data to backend
- Create purchase analysis API
- Implement rule-based scoring logic
- Implement goal delay calculation
- Return analysis result as JSON
- Display analysis results on frontend

---

## Shared Responsibilities

All team members should contribute to:

- UI consistency
- Responsive design
- GitHub pull request reviews
- Bug fixing
- User testing
- HCI documentation
- Final presentation preparation

---

## Git Workflow

Each feature should be developed in a separate branch.

Examples:

feature/onboarding

feature/spending-profile

feature/goals

feature/dashboard

feature/purchase-analysis

feature/history-insights

Feature branches should be merged into:

develop

The final stable version should be merged into:

main
